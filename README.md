<h1>Starbie</h1> <br>
<h1>Description</h1> <br>
Starbie is an interactive desktop companion built following a written hackclub guide on halflife. It is built using XIAO ESP32 as the microcontroller(the brain of the system).<br>
This project is not a complete replication of the guide as it includes some extra features including custom underglowing effects, light, alarm system and interactive features.

<h1>Additional Features explained</h1>
1. Passive Buzzer: It gives Starbie sound. It generates beeping sound effects when it is turned on. Also when emmits sound when buttons and keys are physically used
<br>
2. Light Sensor: Monitors the surrounding light levels using voltage divider circuit. 
When the surrounding seems dark it should automatically switch to sleep mode
<br>
3. RGB Leds: Provides underglow effect to the starbie depending on the current situation. green on successful booting and others
